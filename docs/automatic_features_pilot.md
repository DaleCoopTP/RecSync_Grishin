# Коммит 23: малый запуск на реальных данных и аудит ресурсов

Полный жизненный цикл выполнен на отдельной случайной когорте из **1000**
пользователей исходной фиксированной выборки. Сохранены все **5676** доступных
записей выбранных пользователей; строки истории не сэмплировались.

Срезы пилота: обучение 12/19/26 июля 2021; внешняя валидация 2 августа;
исторический условный тест 9–15 августа. Основная тестовая неделя 16–22 августа
не оценивалась. Пилотные метрики не используются для изменения основной гипотезы,
грамматики, признаков или бюджета поиска.

## Проверено

- Подготовка отдельного baseline и всех входных артефактов без изменения основного.
- Генерация 504 описанных признаков; 502 прошли удаление констант/дубликатов.
- Внутренний поиск, семь внешних сравнений, фиксация метода, четыре финальных
  переобучения и историческая оценка.
- Загрузка моделей, совпадение предсказаний и метрик, повторный запуск без
  изменения завершённых моделей.
- SHA 65 защищённых входных файлов основного baseline до и после пилота совпадают.

Пилот использует сокращённые настройки: до 64 внутренних пользователей на срез,
20 деревьев вспомогательной модели, глубина 4, префиксы 8/16. Его собственный
baseline ограничен 30 деревьями; по его валидации сохранено 7. Эти настройки
относятся только к проверке исполнения. Основной конфиг не менялся.

## Измерения и решение о запуске

Весь холодный запуск: **22,30 с**, пик суммы RSS рабочего процесса и потомков
**863,88 МиБ**, два вычислительных потока; лимит 6 GiB не превышен.
Поиск занял 5,56 с, внешняя валидация 2,73 с, историческая финальная оценка
2,94 с, проверка моделей 0,63 с. Повтор финальной команды: 0,02 с.

Это проверка работоспособности, а не линейный прогноз большого обучения:
размер истории, число запросов, глубина и число деревьев различаются.
В основном поиске только плотные массивы 504 float32-признаков для примерно
400000 обучающих и 200000 валидационных пар требуют **1,13 GiB**; к этому
добавляются агрегаты, метаданные и CatBoost Pool. Все 504 признака рассчитываются
только для внутреннего поиска; внешний эксперимент материализует объединение
выбранного и случайного наборов, не более 128 автоматических колонок.

Основной запуск разрешён с уже установленным ограничителем RSS 6 GiB и двумя
потоками, последовательно и с сохранением этапов. Ориентир — 1–3 часа, с учётом
прежних замеров полного baseline; это предварительная оценка, не гарантия.
При превышении памяти требуется оптимизировать исполнение с сохранением
значений и состава данных; сокращать основной протокол по результатам нельзя.

## Воспроизведение

Из корня проекта:

```bash
.venv/bin/python -m scripts.autofeatures_pilot
```

Рабочий каталог — `artifacts/autofeatures/pilot_23/workspace`. При повторе
завершённые этапы проверяются и используются повторно; для холодного запуска
нужно новое имя: `--name pilot_fresh`.

Машинные доказательства: [pilot_23.json](../results/autofeatures/pilot_23.json).
Там записаны состав конфигураций, SHA выборки и исходников, времена, ограничения,
проверка сохранности baseline и отдельный флаг `main_test_evaluated=false`.
Флаг `verification.test_evaluated=true` относится только к историческому пилоту.
